# 서울아산병원 뉴스룸 개편 시안 (시연용 프로토타입)

> ⚠️ **실제 서비스가 아닙니다.** 2026 뉴스룸 웹·앱 통합개편 논의를 위해 제작한 내부 검토용 화면 시안이며,
> 게시된 기사·인물·수치는 모두 화면 구성 확인을 위한 **가상 예시**입니다.

삼성전자 뉴스룸의 카드형 레이아웃을 기준 방향으로 삼아, 직원 의견 취합 결과와 회의 결정 사항을
실제 화면으로 옮긴 정적 프로토타입입니다. 관련 부서·업체 시연에 그대로 사용할 수 있습니다.

---

## 화면 구성

| 파일 | 화면 | 핵심 확인 포인트 |
|---|---|---|
| `index.html` | 뉴스룸 메인 | 카드형 목록, 롤링 축소, 리서치·AI 신설, 건강TV 하단 배치 |
| `article.html` | 기사 상세 | AI 요약, 태깅 확장, 연관 콘텐츠 텍스트형, 이전/다음, 스크랩 |
| `press.html` | 프레스센터 | Fast Facts, 본문 복사, 사진 일괄 다운로드, 미디어 라이브러리 |
| `admin.html` | 통합 등록화면 (CMS) | 이중 입력 제거, 드래그 업로드, AI 자동 태깅, 3종 미리보기 |
| `app.html` | 앱 화면 | 웹·앱 통합 구조, 앱 메인/상세, 푸시 선별 발송 |
| `guide.html` | 개편 포인트 정리 | 의견 비중, 요구사항→화면 매핑표, 로드맵, 업체 확인 사항 |

## 시연 방법

각 화면 우측 하단의 **「개편 포인트」** 버튼을 누르면, 해당 화면에서 무엇이 어떻게 바뀌었고
그 근거가 어느 회의의 어떤 결정인지가 화면 위에 번호와 함께 표시됩니다.
시연 순서는 `guide.html` → `index.html` → `article.html` → `admin.html` → `app.html` 을 권장합니다.

## 반영한 주요 결정 사항

**메인 화면**
- 삼성전자 뉴스룸 방식의 카드형 — 가로 이미지 + 카테고리 + 제목만, 본문 미리보기 제거
- 메인 롤링 배너 높이 축소 (통합 GNB가 상단 공간을 차지하는 점 반영)
- 뉴스룸 자체 서브메뉴는 상단 GNB와 중복 없이 하단 배치
- '리서치·AI' 카테고리 신설 — 기초연구·논문 기반 콘텐츠 분리
- 모바일 첫 화면에 검색창 상시 노출
- 건강TV 영상은 우측 배너가 아닌 메인 하단 기본 영역

**기사 상세**
- 본문 AI 3줄 요약 (AI 생성 표기 + 원문 확인 안내 포함)
- 태그 확장: 의료진 / 질환 / 검사·시술 / 신체부위 / 주제, 기준정보 DB ID 연결
- 연관 콘텐츠를 이미지 롤링 → 텍스트 목록형, 자동 매핑 + 담당자 직접 지정 병행
- 이전 글 / 다음 글 네비게이션 신규
- 좋아요 삭제, 스크랩(별표) 도입
- 공유에서 라인 제거, 링크드인 추가
- 영문 기사가 있을 때만 '영문으로 보기' 노출

**통합 등록화면 (CMS)**
- 아카이브 등록과 뉴스룸 노출을 하나의 화면으로 통합, 체크박스로 채널 선택
- 드래그 앤 드롭 업로드, 허용 형식 확대(zip·xlsx·pptx 등), 용량 상향
- 업로드 사진 클릭으로 대표 썸네일 지정 → 목록·메인·모바일·앱·OG 자동 생성
- 본문에서 태그 자동 추출 후 기준정보 DB 매핑
- 건강TV URL 한 줄 입력으로 제목·썸네일·재생시간 자동 연동
- KEY 생성을 필수에서 선택으로, 취재경로·비고 삭제, 배포범위 버튼식
- 편집기 색상 팔레트에 아산 브랜드 컬러 우선 배치
- PC·모바일·앱 미리보기, 예약 발행, 임시저장·수정이력

**앱 / 구조**
- 앱이 통합 홈페이지의 뉴스룸을 그대로 사용하는 웹·앱 통합 구조
- 콘텐츠 원본 1건 → 웹·모바일·앱·프레스센터·푸시 자동 배포
- 푸시는 상시 구독형이 아닌 운영자 선별 발송

## 기술 사항

- 빌드 도구·의존성 없는 정적 HTML/CSS/JS. `index.html`을 브라우저에서 바로 열면 됩니다.
- 이미지는 외부 파일 없이 CSS 그라데이션 플레이스홀더로 대체했습니다(실제 사진 영역 표시).
- 반응형 — PC / 태블릿 / 모바일 폭에서 모두 확인할 수 있습니다.
- GitHub Pages로 배포하려면 저장소 Settings → Pages → Branch `main` / 루트 선택.

## 남은 결정 사항

`guide.html` 하단의 **업체(디콘) 선확인 필요 사항** 참고 — URL 리다이렉트, 의료진·질환 매핑 이관,
아카이브·노출 화면 통합 범위, KEY 구조, 건강TV 연동, 편집기 팔레트 비용.
