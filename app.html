앱 화면 — 웹·앱 통합

앱에서 뉴스룸을 열면 별도 앱 전용 페이지가 아니라 통합 홈페이지의 뉴스룸 화면이 그대로 표시됩니다. 콘텐츠를 한 번 등록하면 웹·모바일·앱·푸시가 같은 원본을 사용합니다.

16 하나의 콘텐츠, 여러 채널
앱에 들어가려면 뉴스룸이 하나의 카테고리 홈페이지로 통합되어야 합니다. 카드형 레이아웃은 모바일·앱 구현이 쉬워 별도 앱 디자인을 따로 만들 필요가 줄어듭니다.
그래서 앱 메인도 웹 모바일과 같은 구성으로 맞췄습니다. 검색창 아래 주요 태그, 옆으로 밀어 넘기는 롤링, 작은 가로형 목록까지 같은 화면을 폭만 줄여 쓰는 구조라 앱 전용 디자인을 따로 만들 필요가 없습니다. 근거 · 9/1 실무진 회의 「앱으로 들어가려면 하나의 카테고리 홈페이지로 통합되는 방식」 / 9/14 회의 「카드형으로 변경 시 모바일 구현도 용이」 / 9/16 홍보팀 검토 「앱 메인도 모바일과 같은 롤링·목록 구성으로」
