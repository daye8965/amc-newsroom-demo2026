# 썸네일 사진 넣는 곳

이 폴더의 사진이 화면 썸네일로 깔립니다. 파일이 없으면 그라데이션 자리표시가 그대로 보입니다(화면이 깨지지 않습니다).

## 지금 들어 있는 사진

| 파일 | 쓰이는 곳 |
|---|---|
| `hero-01.jpg` | 메인 롤링 첫 장 + 기사 상세 본문 사진 |
| `news-01.jpg` | 메인 「최신 콘텐츠」 첫 번째 카드 |

나머지 자리는 그라데이션 자리표시입니다. 사진이 들어가면 어떻게 보이는지
보여주는 것이 목적이라 일부러 두 장만 넣었습니다.

## 사진을 더 넣으려면

파일을 이 폴더에 넣고, 해당 항목에 `img:` 한 줄을 추가하면 됩니다.

- 메인 롤링 · 카드 · 건강TV → `assets/js/data.js` 의 `hero` / `cards` / `tv`
- 프레스센터 보도자료 → `press.html` 의 `LIST`

```js
{ id:'a2', cat:'리서치·AI', ... , c1:'#00335f', c2:'#00a19a', img:'assets/img/news-02.jpg' },
```

경로에 파일이 없으면 그라데이션 자리표시로 남습니다(화면이 깨지지 않습니다).

## 규격

- **가로형 16:9** 권장 (`1600 x 900` 정도). 세로 사진은 위아래가 잘립니다.
- 한 장당 **300KB 이하**로 줄여주세요. 오프라인 ZIP 시연 때 용량이 커집니다.
- 형식은 `jpg` 권장. `png`·`webp`를 쓰려면 `data.js`의 확장자도 같이 바꿔야 합니다.

## 올리기 전에 확인할 것

이 저장소는 **GitHub에 공개**되어 있고 시연 링크도 누구나 열 수 있습니다.
올린 사진은 링크를 아는 사람이면 볼 수 있습니다.

- 인물 얼굴·명찰이 나온 사진, 환자가 찍힌 사진은 **공개 범위를 한 번 확인**하고 넣으세요.
- 공개하기 곤란하면 파일을 넣되 `.gitignore`에 `assets/img/*.jpg`를 추가하세요.
  내 PC와 ZIP 시연에서는 사진이 보이고, 공개 링크에서는 그라데이션으로 나옵니다.
