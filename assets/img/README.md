# 썸네일 사진 넣는 곳

이 폴더에 아래 이름으로 파일을 넣으면 화면에 바로 붙습니다. **코드를 고칠 필요 없습니다.**
파일이 없으면 지금처럼 그라데이션 자리표시가 그대로 보입니다(화면이 깨지지 않습니다).

## 파일 이름

| 파일 | 쓰이는 곳 |
|---|---|
| `hero-01.jpg` ~ `hero-03.jpg` | 메인 롤링 3건 (`hero-01`은 기사 상세 본문 사진으로도 쓰임) |
| `news-01.jpg` ~ `news-12.jpg` | 메인 「최신 콘텐츠」 카드 12건 (기사 상세의 연관 카드, 앱 목록에도 같이 쓰임) |
| `tv-01.jpg` ~ `tv-04.jpg` | 메인 건강TV 4건 |
| `press-01.jpg` ~ `press-04.jpg` | 프레스센터 보도자료 목록·상세 4건 |

다른 이름을 쓰고 싶으면 `assets/js/data.js`의 각 항목 `img:` 경로만 바꾸면 됩니다.
프레스센터 4건은 `press.html`의 `LIST` 안에 있습니다.

## 규격

- **가로형 16:9** 권장 (`1600 x 900` 정도). 세로 사진은 위아래가 잘립니다.
- 한 장당 **300KB 이하**로 줄여주세요. 오프라인 ZIP 시연 때 용량이 커집니다.
- 형식은 `jpg` 권장. `png`·`webp`를 쓰려면 `data.js`의 확장자도 같이 바꿔야 합니다.

## 올리기 전에 확인할 것

이 저장소는 **GitHub에 공개**되어 있고 시연 링크도 누구나 열 수 있습니다.
올린 사진은 링크를 아는 사람이면 볼 수 있습니다.

- 인물 얼굴·명찰이 나온 사진, 환자가 찍힌 사진은 **공개 범위를 한 번 확인**하고 넣으세요.
- 공개하기 곤란하면 파일을 넣되 `.gitignore`에 `assets/img/*.jpg`를 추가하세요.
  내 PC와 ZIP 시연에서는 사진이 보이고, 공개 링크에서는 그라데이션으로 나옵니다.
