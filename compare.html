현재 vs 개편안

지금 뉴스룸 화면과 개편안을 같은 항목끼리 나란히 놓고 비교한 페이지입니다. 시연에서 이 페이지를 먼저 펼쳐 놓고 개별 화면으로 들어가면 설명이 이어집니다. 왼쪽 목업은 현재 뉴스룸 구조를 단순화해 옮긴 것입니다.

비교 01

메인 화면 전체 구조

현재의 불편

  • 상단 메뉴(뉴스·헬스·피플·프레스센터)와 목록 탭(전체·뉴스·헬스·피플)이 같은 분류를 두 번 노출
  • 롤링 배너가 첫 화면을 거의 차지해 실제 콘텐츠가 아래로 밀림
  • 배너가 가로로만 길어 사진 위아래가 잘림 — 인물 얼굴·현판이 화면 밖으로
  • 썸네일이 작고 세로로만 나열되어 한눈에 훑기 어려움
  • 제목 아래 본문 발췌가 붙어 카드 높이가 들쭉날쭉
  • AMCTV 영상이 우측 배너에만 있어 건강TV 콘텐츠와 중복

개편안

  • 뉴스룸 서브메뉴 한 줄로 통합, 통합 홈페이지 GNB 아래 배치
  • 롤링 높이를 낮추고 3건만 순환 — 카드가 첫 화면에 바로 보임
  • 양 사이드를 잘라 카드와 같은 16:9 — 사진이 잘리지 않음
  • 남는 좌우 공간에 이전·다음 기사를 걸쳐 노출, 눌러서 이동
  • 가로 16:9 카드 3열 — 삼성전자 뉴스룸 방식
  • 카테고리 + 제목만, 본문 발췌 제거로 카드 높이 통일
  • 영상은 메인 하단 기본 영역으로 이동, 우측 배너 중복 해소
  • '리서치·AI' 신설로 기초연구 콘텐츠 분리

현재의 불편

  • 좋아요가 중복 클릭 가능하고 로그인이 없어 데이터 신뢰도가 낮음
  • 연관 콘텐츠가 이미지 롤링이라 제목을 훑을 수 없고 연관 기준도 불명확
  • 상·하편 같은 시리즈를 담당자가 직접 묶을 방법이 없음
  • 이전 글 / 다음 글 이동 기능이 없음
  • 거의 쓰지 않는 라인 공유 버튼이 자리를 차지

개편안

  • 좋아요 삭제, 마이페이지에서 모아보는 스크랩(별표)으로 대체
  • 연관 콘텐츠를 텍스트 제목 목록으로 전환
  • 키워드 자동 매핑 + 담당자 URL 직접 지정 병행
  • 같은 코너 내 이전 글 / 다음 글 이동 신규
  • 라인 제거, 링크드인 추가

비교 05

검색 · 태그

왼쪽 ‘현재’ 목업은 화면 구조를 비교하기 위해 단순화해 옮긴 것으로, 실제 뉴스룸의 세부 디자인과는 차이가 있습니다. 오른쪽 개편안의 색상·폰트·간격은 통합 홈페이지 디자인 시스템이 확정되면 그에 맞춰 조정해야 합니다.
