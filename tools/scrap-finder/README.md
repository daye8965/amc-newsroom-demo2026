# 스크랩 후보 찾기 (scrap-finder)

스크랩마스터에서 이미지로 저장한 **하루치 지면 폴더**를 OCR로 읽어서,
병원·의료 관련 기사가 **어느 신문 몇 면에 있는지** 후보 목록을 만들어 주는 PC용 프로그램입니다.

- 신문을 처음부터 넘기는 대신, 표시된 면만 스크랩마스터에서 오리면 됩니다.
- 스크랩 1쪽 목차 형식의 **초안**(`목차초안.txt`)도 함께 만듭니다.
  `: 서울아산병원 피부과 ○○○ 교수 도움말` 줄까지 자동으로 채웁니다.
- 인터넷이 필요 없고, 지면이 PC 밖으로 나가지 않습니다.

> 뉴스룸 시연 화면과는 별개의 내부 업무 도구입니다. 지면 이미지는 저작권 때문에 이 저장소에 올리지 마세요.

## 설치 (PC당 한 번)

1. **Python 설치**
   [python.org](https://www.python.org/downloads/)에서 받아 설치합니다.
   설치 첫 화면에서 **「Add python.exe to PATH」에 꼭 체크**하세요.
2. **Pillow 설치**
   명령 프롬프트(cmd)를 열고 아래 명령을 실행합니다.
   ```
   pip install pillow
   ```
3. **Tesseract OCR 설치**
   [UB Mannheim 배포판](https://github.com/UB-Mannheim/tesseract/wiki)에서 Windows 설치 파일을 받습니다.
   설치 중 *Additional language data*에서 **Korean**에 체크하세요.
   설치 위치는 기본값(`C:\Program Files\Tesseract-OCR`) 그대로 두면 프로그램이 알아서 찾습니다.
4. 이 폴더(`tools/scrap-finder`)를 PC로 내려받습니다. 저장소에서 **Code → Download ZIP**을 누르면 됩니다.

## 매일 쓰는 법

1. 스크랩마스터에서 그날 지면을 이미지로 저장합니다. 신문별 하위 폴더로 나눠도 됩니다.
2. 그 폴더를 **`실행.bat` 위로 끌어다 놓습니다.** 실행.bat을 더블클릭한 뒤 폴더를 끌어다 놓아도 됩니다.
3. 처음 읽을 때는 면당 5~10초가 걸립니다. 끝나면 결과 화면이 자동으로 열립니다.
   같은 폴더를 다시 돌리면 이미 읽은 면은 건너뛰어서 몇 초 만에 끝납니다.

결과는 지면 폴더 안의 `_스크랩후보` 폴더에 생깁니다.

| 파일 | 내용 |
|---|---|
| `결과.html` | 왼쪽: 분류별 후보 목록 / 오른쪽: 키워드를 형광펜으로 칠하고 추정 제목에 빨간 테두리를 친 지면 |
| `목차초안.txt` | 스크랩 1쪽 형식의 초안. 복사해서 고쳐 쓰면 됩니다 |
| `결과.json` | 같은 내용의 데이터 (나중에 월별 집계 등에 사용) |

## 키워드 바꾸기

`키워드.txt`를 메모장으로 열어 고치면 됩니다. 프로그램을 수정할 필요는 없습니다.

```
[서울아산병원]          ← 하나만 나와도 후보
서울아산병원
울산의대

[의료/정책 min=3]       ← 한 기사에 3번 이상 나와야 후보 (흔한 단어용)
보건복지부
전공의
```

- 위에 적힌 분류가 우선합니다.
- 띄어쓰기는 무시합니다.
- 5글자 이상 키워드는 OCR 오타도 잡습니다. 예를 들어 `서울야신병원`도 `서울아산병원`으로 찾습니다.

## 알아 둘 점 (11/19 지면 15면으로 시험한 결과)

- **잘 되는 것:** 병원명 찾기와 `○○과 ○○○ 교수` 추출. 경향신문 H01면 「뜨거운 물 샤워」 기사를 찾아냈고, 실제 스크랩과 같은 도움말 줄을 만들었습니다.
- **반드시 사람이 확인할 것:**
  - **제목:** 큰 글씨 줄을 제목으로 추정하는 방식이라 틀리거나 비어 있을 수 있습니다.
  - **매체·면 번호:** 지면 머리글에서 읽는데, 로고가 그림인 신문(예: 헬스경향)은 비어 있을 수 있습니다.
    이럴 때는 폴더나 파일 이름에 매체명과 면 번호(`A12` 형식)가 들어 있으면 그것을 씁니다.
  - **서울아산병원과 무관한 의료/정책 기사:** 병원명만으로는 판단이 어려워 놓칠 수 있습니다.
    이 분류는 `키워드.txt`의 [의료/정책] 목록을 다듬어 가며 맞춰야 합니다.
- **해상도:** 저장한 이미지의 해상도가 높을수록 정확합니다. 가로 2600픽셀보다 작은 이미지는 자동으로 확대해서 읽습니다.
